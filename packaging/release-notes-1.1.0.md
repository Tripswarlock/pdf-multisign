PDF Мультиподпись 1.1.0 — подпись PDF несколькими подписями CryptoPro на одном компьютере и по локальной сети.

## Что нового в 1.1.0

- **Сетевая подпись по ЛВС**: один компьютер создаёт сессию («Создать сессию…»), показывает адрес и код; остальные присоединяются («Присоединиться…»), выбирают свой сертификат и подписывают документ своим ключом CryptoPro.
- **Статусы участников** в реальном времени: «оформляет подпись», «✓ подписал (время, № подписи)», «ошибка» — видны у ведущего и у каждого участника; участникам приходят обновления документа после каждой новой подписи.
- Последовательная модель: каждый следующий участник подписывает документ вместе с предыдущими подписями, очередность фиксируется инкрементальными ревизиями PDF.
- Безопасность ключа: закрытый ключ не покидает компьютер участника — по сети передаются только подготовленные байты для подписи и готовая CMS. Ведущий проверяет `messageDigest` (Streebog-256) до встраивания подписи.
- Очередь подписания: одновременно оформляется одна подпись, остальные ждут; неверная или чужая подпись отклоняется, резерв автоматически снимается.

## Сборки

- `PDF-Multisign-1.1.0-win64.msi` — установщик для Windows 10/11 x64;
- `PDF-Multisign.exe` — portable-сборка для Windows;
- `pdf-multisign_1.1.0_amd64.deb` — пакет для Debian 12 / Astra Linux 1.8 / Ubuntu 22.04+.

## Требования

- CryptoPro CSP 5.0 R2+ (CAdES Browser Plug-in на Windows) — устанавливается отдельно;
- сертификат с закрытым ключом в контейнере CryptoPro на каждом компьютере-участнике;
- для сетевого режима: компьютеры в одной ЛВС, у ведущего открыт порт (по умолчанию 8471). Обмен по HTTP внутри ЛВС защищён кодом сессии — не используйте в недоверенных сетях.

## Проверено

- Windows 11 x64 + CryptoPro CSP 5.0: две подписи в одном PDF (VerifyCades + ГОСТ-хеш), PDFium видит обе;
- офлайн-тест сетевой сессии `tests/test_network.py`: два участника по очереди подписывают через реальный HTTP-сервер, статусы корректны, чужой commit и CMS с неверным хешем отклоняются;
- Astra Linux 1.8.6: `.deb` устанавливается, интерфейс запускается, `cryptcp`/`certmgr` определяются.
