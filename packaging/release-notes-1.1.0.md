PDF Мультиподпись 1.1.0 — подпись PDF несколькими подписями CryptoPro на одном компьютере и по локальной сети.

## Что нового в 1.1.0

Сетевая подпись по сценарию «организатор + участники»:

- **Выбор роли**: «Сетевая подпись» → организатор создаёт сессию или участник присоединяется.
- **Две схемы подписания**:
  - *последовательная* — каждый участник подписывает текущую версию документа, подписи встраиваются в один PDF цепочкой ревизий (можно включить строгую очередь);
  - *параллельная (соподпись)* — каждый независимо подписывает исходный файл, итог: PDF + отдельные `.sig` (CAdES) каждого подписанта.
- **Статусы**: ожидает / подписывает / подписан / отказался / ошибка — у организатора, у участников и на **веб-странице сессии** (открывается в браузере по адресу сессии, автообновление каждые 5 с — удобно на общем экране).
- **Отказ от подписи** участником; организатор видит отказ сразу.
- Код сессии из 6 символов (без похожих букв), токен участника, защита от повторного присоединения тем же сертификатом, автоподбор порта (8443+).
- Кнопка «Скопировать приглашение» — адрес, код и инструкция одним сообщением.
- Загрузка PDF **кликом по рамке** переноса файла (не только перетаскиванием и кнопкой).
- Диалог «О программе» без версии ОС.
- Окно параметров сессии: сначала «Параллельная подпись», затем «Последовательная подпись» с вложенными «Строгая очередь» и «Видимый штамп подписи в документе».
- Интерфейс: радиокнопки — круглые индикаторы с заливкой внутри в выбранном состоянии (в том числе в собранной версии), у выпадающих списков появилась стрелка вниз, неактивный список явно различим (пунктирная рамка, блёклая стрелка).
- В списке «Страница штампа» добавлен пункт «Все страницы» — штамп ставится на каждую страницу документа.

Подпись остаётся корректной по `/ByteRange`: в последовательной схеме участник
получает от организатора точные байты для подписи (двухфазный протокол
prepare/commit), закрытый ключ не покидает его компьютер, а организатор
проверяет Streebog-256 `messageDigest` до встраивания CMS.

Также в 1.1.0: Material Design с синей палитрой и едиными скруглениями кнопок,
невидимая подпись по умолчанию, иконка приложения в окне и панели задач,
диалог «О программе» со ссылкой на репозиторий, MSI-установщик (WiX).

## Сборки

- `PDF-Multisign-1.1.0-win64.msi` — установщик для Windows 10/11 x64;
- `PDF-Multisign.exe` — portable-сборка для Windows;
- `pdf-multisign_1.1.0_amd64.deb` — пакет для Debian 12 / Astra Linux 1.8 / Ubuntu 22.04+.

## Требования

- CryptoPro CSP 5.0 R2+ (CAdES Browser Plug-in на Windows) — устанавливается отдельно;
- сертификат с закрытым ключом в контейнере CryptoPro на каждом компьютере-участнике;
- для сетевого режима: компьютеры в одной ЛВС, у организатора открыт порт (по умолчанию 8443). Обмен по HTTP внутри ЛВС защищён кодом сессии — не используйте в недоверенных сетях.

## Проверено

- офлайн-тест `tests/test_network.py` через реальный HTTP-сервер: последовательный режим (двое участников, очередь резервирования, отказ чужой подписи, отклонение CMS с неверным хешем, отказ участника), параллельный режим (сбор двух `.sig` с корректными хешами исходного файла), строгая очередь;
- `tests/check_structure.py` — без регрессий;
- `.deb` устанавливается и запускается на Astra Linux 1.8.6 (VirtualBox, CryptoPro CSP 5.0.13000).
